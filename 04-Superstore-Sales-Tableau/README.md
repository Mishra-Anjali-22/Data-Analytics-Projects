# Superstore Sales Dashboard

**Tools:** Tableau

Interactive analytics report for the Superstore USA dataset (orders and returns), with a parameter that lets the viewer switch the whole dashboard between **Sales**, **Profit** and **# Orders**.

## Dashboard contents

- **KPI sheets:** Sales, Profit Margin, Return Rate
- **Map** of performance by state
- **Sales Trend** over time
- **Sales by Segment**
- **Category** and **Sub-category** breakdowns, with a dashboard action filtering sub-categories by the selected category
- **Top 5 Products** using a rank calculation
- Filters for order year and region

## Techniques used

Parameters, calculated fields (profit margin, return rate, top-N rank), joined Orders and Returns data sources, and dashboard filter actions.
